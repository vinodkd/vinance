Features

Accounts & Imports

  • Create accounts with type and currency
  • Import OFX / QFX files from any bank
  • Duplicate detection via FITID
  • Multi-currency support
  • Total balance across all accounts

Categorisation

  • Hierarchical categories (unlimited depth)
  • Rule-based auto-categorisation on import
  • Match by payee or memo (substring or regex)
  • Priority ordering for overlapping rules
  • Re-apply all rules at any time
  • Manual override per transaction

Transfers

  • Link debit/credit pairs across accounts
  • App finds the best match automatically
  • Transfers excluded from income/expense totals
  • Unlink with one click

Reports

  • Income vs expense bar chart by month
  • Expense breakdown pie chart by category
  • Custom date range with presets
  • Click any chart element to drill into transactions

Budgets

  • Monthly or yearly budgets per category
  • Actual spend rolls up from child categories
  • Budget vs actual bar chart
  • Variance column (green = under, red = over)
  • Drill down to matching transactions

Portfolios

  • Named portfolios backed by .vinance files
  • Create or open from any location
  • Set a default (auto-opened on launch)
  • Hot-switch without restarting the app
  • Recent portfolio list with last-opened time

Getting started

Install

Download the latest release for your OS from the Releases page, or run from source:

git clone https://github.com/vinodkd/vinance.git
cd vinance
npm install
npm run dev

Create a portfolio

On first launch you land on the Portfolios page. Click + New, give it a name (e.g. "Personal"), and choose where to save the .vinance file.

Import your bank data

Go to Overview and click Import OFX/QFX. Most online banking portals let you export OFX or QFX files under "Download transactions" or "Export". Re-importing the same file is safe — duplicates are skipped automatically.

Set up categories and rules

Go to Categories and create a hierarchy that matches your life (e.g. Food → Groceries, Food → Dining Out). Then go to Rules and create patterns to auto-assign categories. Hit Re-apply all rules to categorise existing transactions in one go.

Link transfers

In Transactions, find a transaction that moved money between your accounts (e.g. a savings deposit). Click ⇄ transfer, select the other account, and confirm the match Vinance found. Linked transfers are excluded from reports so they don't inflate your income or expenses.

Explore reports and budgets

Head to Reports for income/expense charts. Click any bar or pie slice to drill into the underlying transactions. In Budgets, set a spending target per category and track variance over time.

Typical monthly workflow

1

Download OFX/QFX from your bank

Export the last month of transactions from each account.

2

Import into Vinance

Click Import more on each account. Rules run automatically; new categories apply instantly.

3

Review uncategorised transactions

Filter by "Uncategorized" in Transactions, assign categories, and add new rules for recurring payees.

4

Link any transfers

Mark savings deposits, loan payments, or account top-ups as transfers so they don't skew your reports.

5

Check reports and budgets

See where you're over or under budget, drill into categories that look unusual.
